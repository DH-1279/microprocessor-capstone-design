# 비전 기반 햅틱 글러브

> 책상 위 필요한 물건까지, 손끝의 진동으로 안내합니다.

**시각장애인 및 저시력자의 실내 물건 탐색을 돕는 카메라 기반 촉각 안내 시스템**입니다. 고정형 카메라로 목표 물체와 사용자의 손을 함께 추적하고, 장갑의 진동을 통해 손을 움직일 방향과 물체에 가까워지는 정도를 전달하는 것을 목표로 합니다.

2026학년도 2학기 마이크로프로세서 캡스톤디자인에서 **김가네** 팀이 개발하고 있습니다.

## 프로젝트 추진 배경

책상 위에서 지갑이나 리모컨을 찾아 손에 쥐는 일은 물건의 종류를 알아보는 것뿐 아니라, 위치를 파악하고 손을 정확히 움직이는 과정까지 필요합니다. 시각장애인과 저시력자는 이러한 과정에서 주변을 손으로 더듬거나 다른 사람의 도움을 구해야 하는 상황을 겪을 수 있습니다.

손으로 물건을 찾는 동안 다른 물건을 넘어뜨릴 수 있고, 위치에 대한 설명을 들어도 손을 어느 방향으로 얼마나 움직여야 하는지 판단하기 어려울 수 있습니다. 이 프로젝트는 물체와 손 사이의 위치 관계를 촉각으로 전달해 일상적인 물건 탐색을 돕고자 합니다.

## 해결하려는 문제

| 탐색 과정의 어려움 | 프로젝트의 접근 |
|---|---|
| 찾으려는 물건이 책상 어디에 있는지 파악하기 어려움 | 카메라 영상에서 목표 물체를 탐지하고 위치를 추적 |
| 물건의 위치를 알아도 손을 움직일 방향을 판단하기 어려움 | 손과 물체의 상대 위치를 진동 패턴으로 전달 |
| 손을 회전하거나 뒤집으면 안내 방향이 혼동될 수 있음 | 손의 자세를 고려해 진동 안내를 조정 |
| 음성 설명만으로 이동 중의 위치 변화를 계속 따라가기 어려움 | 진동으로 방향과 근접도를 전달하고 필요한 음성 안내를 함께 제공 |

## 서비스 대상과 사용 환경

**주요 대상은 실내에서 작은 생활용품의 위치를 확인하고 손을 뻗어 찾는 데 도움이 필요한 시각장애인과 저시력자입니다.**

초기 사용 환경은 고정형 카메라 한 대가 관찰하는 제한된 책상 위 공간으로 설정합니다. 가정의 개인 책상이나 생활 훈련 공간 등에서 활용하는 것을 구상하고 있습니다. 탐색 대상은 사전에 선정한 생활용품으로 시작하며, 구체적인 종류와 촬영 범위는 초기 시험을 통해 정합니다.

## 핵심 기능

아래 기능을 연결해 물체 선택부터 손의 접근까지 이어지는 안내를 구현하고자 합니다.

### 목표 물체와 손의 위치 인식

카메라 영상에서 찾으려는 물체와 사용자의 손을 함께 추적합니다. 손이 이동할 때마다 두 위치의 관계를 갱신해 안내에 반영합니다.

### 손가락별 진동을 통한 방향 안내

장갑에는 **손가락마다 진동 모터를 하나씩, 총 5개** 배치합니다. 각 모터의 진동 조합으로 손을 움직일 방향을 표현하며, 사용자가 쉽게 구분할 수 있는 패턴을 시험해 정합니다.

### 물체에 가까워지는 정도 전달

목표 물체에 가까워질수록 진동의 반복 간격을 줄이는 방식으로 근접도를 안내합니다. 방향 정보와 함께 전달해 손의 이동을 조절하도록 돕습니다.

### 손의 자세를 반영한 안내

손의 회전과 손바닥·손등 전환을 고려해 안내 방향을 조정합니다. 영상 기반 손 추적과 장갑의 자세 센서를 활용하는 방식을 검토합니다.

## 사용 흐름

다음은 구현하려는 기본 사용 시나리오입니다.

1. **장갑 착용과 탐색 준비** — 사용자가 장갑을 착용하고 카메라가 관찰하는 책상 위에서 탐색을 시작합니다.
2. **목표 물체 선택** — 찾으려는 물건을 선택하면 시스템이 영상에서 해당 물체를 찾습니다.
3. **진동을 따라 손 이동** — 손과 물체의 상대 위치에 따라 진동 안내를 제공하고, 사용자는 이를 따라 손을 움직입니다.
4. **근접 안내와 물건 확인** — 목표에 가까워지면 달라지는 진동 패턴을 통해 접근 상태를 파악하고, 사용자가 물건을 직접 확인해 집습니다.

목표 물체를 선택하는 입력 방식과 도달 판정 기준은 초기 시제품 시험에서 구체화합니다.

## 시스템 구성

| 구성 요소 | 역할 |
|---|---|
| 고정형 카메라 1대 | 책상 위 목표 물체와 사용자의 손 촬영 |
| 메인 영상 처리 장치 | 물체·손 추적, 상대 위치 계산, 진동 안내 명령 생성 |
| ESP32 기반 장갑 디바이스 | 무선 명령 수신과 손가락별 모터 5개 제어 |
| 자세 센서와 전용 PCB | 손의 움직임을 파악하고 제어·전원·모터 구동 회로를 장갑에 통합 |

## 초기 시제품 목표와 확장 방향

**첫 시제품은 제한된 책상 환경에서 목표 물체 하나를 선택하고, 손의 위치 변화에 맞춰 진동으로 안내하는 전체 과정을 연결하는 데 집중합니다.**

기본 안내 기능을 검증한 뒤에는 “지갑 찾아줘”와 같은 음성 요청을 인식하고 탐색 상태를 음성으로 알려주는 기능을 확장할 계획입니다. 이후 상황에 맞는 물건을 찾는 요청으로 활용 범위를 넓히는 방안도 검토합니다.

## 기대효과와 평가 방향

사용자가 필요한 물건을 스스로 찾는 경험을 지원하고, 물건을 찾기 위해 주변을 더듬는 과정에서 발생하는 불필요한 접촉을 줄이는 것을 기대합니다. 촉각과 음성을 함께 활용해 탐색 정보를 이해할 수 있는 방법을 넓히고자 합니다.

효과는 **물체 탐색 성공률, 탐색 소요 시간, 방향 안내 정확도**를 중심으로 확인할 계획입니다. 장갑의 착용 편의성과 진동 패턴의 구분 가능성도 함께 살펴봅니다. 구체적인 목표 수치는 초기 시험 결과를 바탕으로 정합니다.

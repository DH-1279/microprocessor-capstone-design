# Microprocessor Capstone Design

> 2026학년도 2학기 마이크로프로세서 캡스톤디자인 프로젝트를 위한 팀 협업 저장소입니다.

## 프로젝트 개요

- **저장소 이름:** `microprocessor-capstone-design`
- **과목:** 마이크로프로세서 캡스톤디자인
- **수행 기간:** 2026년 9월 ~ 2026년 12월
- **프로젝트 주제:** 팀 논의 후 확정 예정
- **참여 인원:** 3명

이 저장소는 캡스톤디자인 프로젝트의 기획, 설계, 개발, 실험 결과와 발표 자료를 팀원들이 함께 관리하기 위해 사용합니다. 구체적인 프로젝트 주제와 구현 목표는 팀 회의를 통해 확정한 뒤 업데이트할 예정입니다.

## 전체 목표

1. 마이크로프로세서를 활용해 실제 문제를 해결할 수 있는 프로젝트를 기획합니다.
2. 하드웨어와 소프트웨어를 연동한 시제품을 설계하고 구현합니다.
3. 역할 분담과 GitHub 협업을 통해 프로젝트를 체계적으로 관리합니다.
4. 반복적인 실험과 검증을 통해 결과물의 완성도를 높입니다.
5. 최종 시연, 발표 자료와 결과보고서를 완성합니다.

## 진행 일정

| 기간 | 주요 목표 |
|---|---|
| 2026년 9월 | 팀 구성, 주제 선정, 요구사항 분석 및 개발 계획 수립 |
| 2026년 10월 | 시스템 설계와 1차 시제품 구현 |

일정은 수업 운영 계획과 프로젝트 주제가 확정된 후 조정할 수 있습니다.

## 저장소 운영 원칙

- 기능이나 문서 작업마다 별도의 브랜치를 생성합니다.
- 작업 내용은 Pull Request를 통해 검토한 후 `main` 브랜치에 병합합니다.
- 해야 할 일과 오류는 GitHub Issue에 등록하고 담당자를 지정합니다.
- 하나의 커밋에는 하나의 논리적인 변경만 포함합니다.
- 개인정보, 비밀번호, API 키와 외부 공개가 제한된 자료는 커밋하지 않습니다.

신청서의 내용을 바탕으로 문장과 표기를 다듬었다. 실제 회의 참석자나 결정되지 않은 담당자·일정은 임의로 기재하지 않았다.

## 1. 과제명

**국문**

시각장애인 및 저시력자의 실내 물건 탐색을 위한 비전 기반 햅틱 글러브 시스템 개발

**영문**

Development of a Vision-Based Haptic Glove System for Indoor Object Finding for People Who Are Blind or Have Low Vision

신청서상 과제유형은 기업연계형이며, 분야는 디스플레이·반도체계열이다. 참여기업과 구체적인 연계 활동은 아직 작성되지 않았다.

## 2. 과제의 목적 및 필요성

시각장애인과 저시력자는 실내에서 물건의 종류나 존재 여부를 알더라도, 정확한 위치를 파악하고 손을 뻗어 집는 데 어려움을 겪을 수 있습니다. 책상 위를 손으로 더듬어 찾는 과정에서는 물건을 넘어뜨리거나 뜨거운 컵, 날카로운 도구 등에 접촉할 위험도 있습니다. 따라서 물체를 인식해 알려주는 기능과 함께, 사용자의 손이 해당 위치에 도달하도록 돕는 안내가 필요합니다.

본 과제는 고정형 탑뷰 카메라로 목표 물체와 사용자의 손을 동시에 추적하고, 장갑 형태의 햅틱 기기로 이동 방향과 근접도를 안내하는 시스템을 개발하고자 합니다. 손의 회전과 뒤집힘에 따라 진동 위치를 조정하고, 필요한 음성 안내를 함께 제공하여 사용자가 안내를 쉽게 이해하고 물건을 찾아 집을 수 있도록 합니다. 이를 통해 물체의 인식부터 도달 동작까지 연결하고, 시각장애인과 저시력자의 독립적인 일상생활을 지원하는 것이 목표입니다.

## 3. 과제 수행 방법 및 과제 결과물 개발 계획

고정형 카메라로 책상 위를 촬영하고, PC에서 YOLO 모델로 목표 물체를 찾습니다. 손 관절 인식을 통해 손의 위치와 방향을 파악하며, 인식이 불안정한 경우 보조 센서의 활용을 검토합니다. 물체와 손의 상대 위치를 바탕으로 이동 방향을 계산하고, 손이 회전하거나 뒤집혀도 알맞은 위치에서 진동이 발생하도록 제어합니다. 제어 신호는 BLE 또는 Wi-Fi로 ESP32에 전달하며, 글러브에 부착한 진동 모터 4개로 방향을 알려주고 물체에 가까워질수록 진동 간격을 줄입니다. 제어 회로와 전원 회로는 하나의 PCB로 제작해 크기와 배선을 줄이고, 완성된 시제품의 물체 탐색 성공률과 소요 시간, 방향 안내 정확도를 확인합니다.

## 4. 기대효과 및 활용 방안

본 시스템은 시각장애인과 저시력자가 실내에서 필요한 물건을 스스로 찾아 집을 수 있도록 도와 일상생활의 자립도와 편의성을 높이고자 합니다. 물건을 찾기 위해 주변을 더듬는 과정에서 발생하는 불필요한 접촉이나 물건의 넘어짐을 줄이는 효과도 기대됩니다. 또한 음성 안내에만 의존하지 않고 촉각 피드백을 함께 제공하므로, 주변 소음으로 음성을 듣기 어렵거나 청각 정보 이용에 제약이 있는 사용자에게도 위치 안내를 제공할 수 있습니다. 가정 내 책상이나 시각장애인 복지관의 생활 훈련실 등에서 활용할 수 있습니다.

추후에는 Whisper 기반 음성 인식을 연동하여 “지갑 찾아줘”라는 요청에 탐색 대상을 음성으로 확인해 주고, 진동으로 손을 해당 위치까지 안내할 계획입니다. 이후 LLM 및 VLM을 활용해 “외출할 때 필요한 물건 찾아줘”와 같은 상황별 요청으로 확장할 수 있습니다.

## 5. 현재 개발 방향

| 구분 | 개발 방향 |
|---|---|
| 초기 사용 환경 | 고정형 카메라가 관찰하는 제한된 책상 위 공간 |
| 탐색 대상 | 사전에 선정한 소형 생활용품. 대상 종류와 수량은 추후 결정 |
| 영상 처리 | PC에서 YOLO 기반 물체 탐지와 손 관절 인식 수행 |
| 손 방향 반영 | 화면의 좌우를 그대로 사용하지 않고 손의 회전·뒤집힘을 고려해 모터 선택 |
| 손 추적 기준 | 손 관절 인식을 기본으로 검토하며, 손등 마커를 필수 구성으로 두지 않음 |
| 보조 센서 | 인식·높이 판단을 보완할 필요가 있는지 시험한 후 선정 |
| 무선 통신 | BLE 또는 Wi-Fi. 최종 방식은 구현·전력 시험 후 선정 |
| 글러브 제어 | ESP32에서 명령을 수신하고 진동 모터 4개 제어 |
| 진동 안내 | 모터 위치로 이동 방향을 전달하고, 가까워질수록 진동 반복 간격을 줄임 |
| 기판 | 제어·전원·모터 구동 회로를 전용 PCB로 통합하는 방향 |
| 평가 | 물체 탐색 성공률, 탐색 소요 시간, 방향 안내 정확도 |

최종 결과물은 햅틱 글러브 시제품, PC 영상 처리·안내 프로그램, ESP32 제어 펌웨어, PCB 설계 자료 및 성능 평가 자료로 정리한다.

## 6. 추가 검토 사항

### 손의 뒤집힘과 실제 높이는 구분

- 손바닥·손등 전환과 회전은 손의 자세에 관한 문제다. 손 관절 인식을 기본으로 하고, 필요한 경우 IMU 보완을 검토한다.
- 손이 물체보다 높이 떠 있는지는 실제 위치에 관한 문제다. 2D 화면에서 손과 물체가 겹친다는 이유만으로 도달을 판단하지 않는다.
- 카메라 옆 다중 구역 ToF 센서, RGB-D 카메라, 보정된 다중 카메라 등을 논의했으나 적용 방식은 확정하지 않았다.
- ToF를 사용할 경우 손·소형 물체·책상의 깊이를 구분할 수 있는지와 카메라 좌표 대응을 먼저 확인한다.
- 추적이나 거리 판단이 불확실할 때의 안내 중단·재개 조건을 정한다.

### 부품과 착용 구조

- ESP32 세부 모델, 진동 모터 모델, 배터리 용량은 확정하지 않았다.
- 3V 코인형 ERM 모터와 500mAh급 1셀 배터리는 초기 시험 후보로 논의했다. 부품 선정은 착용감과 소비전류 측정 후 확정한다.
- 손끝의 촉각과 손목 움직임을 방해하지 않는 글러브 구조를 시험한다.
- 모터 위치별 진동 구분이 가능한지 확인한 뒤 PCB와 케이스 크기를 정한다.

### 소프트웨어와 확장 기능

- FastAPI, WebSocket, 특정 손 인식 라이브러리는 필수 구현 조건으로 확정하지 않았다.
- Whisper는 음성 요청을 인식하는 역할이며, 응답 음성은 별도의 음성 출력 기능으로 구성한다.
- LLM·VLM을 이용한 상황별 탐색은 후속 확장 방향으로 둔다.
- 손 이동 경로와 탐색 시간을 이용한 개인별 안내 조정도 후속 연구 아이디어로 논의했으며, 데이터 수집 시 사용자 동의를 전제로 한다.

- 작성일: 2026-11-02 · 작성자: DH

- 기준: 원격 최신 `2571026`을 pull해 타겟 매핑과 점수 임계값 0.1 변경을 받은 뒤 수정했다.
- 배포 범위: 검증한 목록 안정화 변경을 ver2 개인 브랜치에 반영한다. 기존 `DH-1279/2026-11-02` 및 main에는 병합하지 않는다.

## 1. 문제와 범위 확인

물건 목록을 안내하는 시점에 프레임마다 탐지가 빠져 물건이 나타났다 사라졌다 했다. 사용자가 손을 위로 올릴 때의 문제도, 목표 선택 후 획득이 아니라 **시동어·목표 선택을 기다리는 상태에서 물건이 사라지는 상황**이라고 확인했다.

따라서 `WAIT_WAKE`·`WAIT_TARGET`에서 목록과 표시를 안정화한다. `SEARCHING`의 목표 잠금·손 관측 유효성·방향 안내·획득 판정은 변경하지 않는다. 기존 5초 간격 손 미인식 안내도 이번 범위에서 변경하지 않는다. 앞서 논의했던 손 소실 3초 안내가 아니라 **물건 목록 유지 시간 3초**를 적용한다.

## 2. 목록 등록과 유지

| 설정 | 기본값 | 의미 |
|---|---:|---|
| 목록 확인 창 | 5프레임 | 최근 유효 프레임의 탐지 이력 |
| 등록에 필요한 탐지 | 3번 | 창 안에서 같은 종류가 3번 관측되면 등록 |
| 목록 유지 시간 | 3초 | 마지막 실제 관측 이후 목록·보관 박스 유지 |
| 선택 재확인 대기 | 2초 | 선택한 물건의 새 위치를 기다리는 최대 시간 |

- 물건 종류별 목록이다. 같은 종류의 여러 개체를 별도 추적하는 기능은 아니다.
- 같은 프레임의 같은 라벨 박스가 여러 개 있어도 투표는 한 번만 센다.
- 반복·오래된·미래 시각의 프레임으로 등록 투표나 관측 시각을 갱신하지 않는다.
- 프레임 사이가 기존 `max_age`보다 벌어지면 미확정 투표를 다시 모은다.
- 실제 관측이 3초 이상 없으면 목록에서 제거한다. 목록에 남겨 둔 것 자체가 유지 시간을 연장하지 않는다.
- 목록 순서를 고정해 집합 순서 때문에 음성·표시가 바뀌는 것을 줄인다.
- TTS에 전달하는 목록은 요청 당시 한 문장으로 고정한다. 이후 프레임이 이미 예약된 문장을 수정하지 않는다.

물체를 계속 새로 탐지하는 것과 마지막 탐지 결과를 잠시 기억하는 것은 다르다. 이번 기능은 후자이며, 모델 재학습·추적기·HEF 내부 NMS 변경을 포함하지 않는다.

## 3. 화면 표시와 목표 선택

현재 탐지 박스는 기존처럼 표시한다. 대기 상태에서 현재 탐지는 없지만 목록 유지 시간이 남은 물건은 마지막 박스를 점선과 `[LIST HOLD] 라벨 경과시간`으로 표시한다. 이는 목표 선택 후의 `[LOCKED]` 박스와 구분된다.

목록 유지용 박스를 그대로 제어에 쓰면 사라지거나 움직인 물체의 예전 위치로 안내할 수 있다. 따라서 다음 절차를 적용했다.

1. 목록 또는 현재 관측에 있는 물건 이름을 말하면 선택 요청을 보관한다.
2. 현재 안 보이면 “물체 위치를 다시 확인하고 있습니다.”라고 한 번 안내한다.
3. 최대 2초 안에 유효한 새 프레임의 실제 탐지와 목록 확인 조건을 만족하면 해당 **새 박스·원본 관측 시각**으로 기존 안내를 시작한다.
4. 확인하지 못하면 “물체 위치를 확인하지 못했습니다. 다시 말씀해주세요.”라고 안내하고 `WAIT_TARGET`에 머문다.
5. 취소하면 선택 요청을 지우고 시동어 대기로 돌아간다. 다른 물건을 말하면 이전 선택 대기를 교체한다.

확인 대기 중에는 새 목표의 진동 안내·획득 이벤트를 생성하지 않는다. 확인 시간이 지난 뒤 물체가 다시 나타나도 이전 요청으로 자동 안내를 시작하지 않는다.

## 5. 설정과 시험

기존 실행 명령에 옵션을 생략해도 새 기본값이 적용된다. 값을 바꿔 비교하려면 다음처럼 사용한다.

```bash
python -u KHS_KMJ_vision/detector.py \
  --address 9C:CC:01:82:75:8A \
  --mode 3 --reach-px 75 --reach-frames 8 \
  --list-hold 3 --list-window 5 --list-hits 3 --selection-wait 2
```

# 📘 detector3.py 심층 코드 분석 및 시스템 아키텍처 명세서

## 1. 문서 개요 (Overview)
`detector3.py`는 라즈베리 파이 5(Raspberry Pi 5) 기반의 시각장애인용 실내 물체 탐색 보조 시스템에서 비전(객체 탐지 및 손 추적)과 오디오(음성 인식 및 음성 합성)를 통합 제어하는 메인 엔트리포인트(Main Controller)입니다.

이 버전에서는 외부 `speech.py` 모듈을 도입하여 자모(Jamo) 편집 거리 기반의 퍼지 매칭, 조사 제거, 그리고 대화형 인텐트(Intent) 파싱 로직을 정교하게 통합했습니다. 이를 통해 "시동어 호출(`캡스톤` 외 이형 발음 포괄) -> 유연한 음성 파싱을 통한 목표 물체 지정 -> 상태별 제어 명령(목록 확인, 안내 취소 등) -> 실시간 손가락-물체 거리 계산 및 가림(Occlusion) 보정 -> 물체 획득 판정"의 전체 파이프라인을 더욱 견고하게 수행합니다.

### 2.1. 오디오 하드웨어 레이어 강제 설정
- 설정 코드: `os.environ["PA_ALSA_PLUGHW"] = "1"`
- 배경 및 목적: `AudioService` 내부에서 사용하는 `sounddevice`(PortAudio 래퍼) 라이브러리가 ALSA 하드웨어 디바이스(`hw:X,Y`)에 직접 접근할 경우, 마이크 하드웨어가 `whisper-cli`의 필수 요구 사양인 16,000Hz 모노(Mono) PCM16 포맷을 네이티브로 지원하지 않으면 스트림 오픈 에러가 발생합니다.
- 해결 방식: 환경 변수 `PA_ALSA_PLUGHW=1`을 선언하여 ALSA의 `plughw` 플러그인 레이어를 거치도록 강제함으로써, 커널/라이브러리 단에서 샘플 레이트와 채널 수를 자동으로 리샘플링(Resampling)하도록 보장합니다.

## 3. 패치 분석 (`patched_decode_hailo_nms`)

### 3.1. 패치 적용 배경
`haptic_mvp.vision` 모듈 내부의 기본 `decode_hailo_nms` 함수는 Hailo NPU의 NMS(Non-Maximum Suppression) 후처리 텐서 출력에서 간헐적으로 발생하는 신뢰도(Score) 범위 초과(0.0 미만 또는 1.0 초과, `NaN`, `Inf`)나 바운딩 박스 좌표 역전 현상에 엄격한 예외를 발생시켜 메인 루프를 중단시킬 위험이 있습니다. 이를 방지하기 위해 런타임에 함수를 덮어쓰는 몽키 패치(Monkey Patch)를 수행합니다.

### 3.2. 단계별 디코딩 및 방어 로직
1. 데이터 구조 순회: `labels`(클래스 이름 리스트)와 `raw`(클래스별 탐지 행렬 리스트)를 `zip()`으로 묶어 순회합니다.
2. 행(Row) 규격 검증: 각 탐지 결과 `row`의 길이가 정확히 5 (`[ymin, xmin, ymax, xmax, score]`)인지 확인합니다.
3. 신뢰도(Score) 정제 및 필터링:
   - `score = float(row[4])` 추출 후 `math.isfinite(score)`로 `NaN`이나 무한대 값을 즉시 배제합니다.
   - `score = max(0.0, min(1.0, score))` 수식을 통해 값을 `[0.0, 1.0]` 구간으로 강제 클리핑(Clipping)합니다.
   - 설정된 임계값(`threshold`, 메인 설정에서는 `0.3`) 미만인 객체는 버립니다.
4. 정규화 좌표 클리핑 및 기하학적 유효성 검증:
   - `ymin`, `xmin`, `ymax`, `xmax` 각각을 `[0.0, 1.0]` 범위로 클리핑합니다.
   - `if xmin >= xmax or ymin >= ymax: continue` 조건을 통해 폭(Width)이나 높이(Height)가 0 이하인 잘못된 박스를 걸러냅니다.
5. 원본 해상도 복원 및 정렬:
   - `haptic_mvp.vision.restore_box((ymin, xmin, ymax, xmax), geometry)`를 호출해 모델 입력 패딩(Letterbox)을 제거한 실제 카메라 비율 좌표를 얻습니다.
   - 탐지된 모든 `Detection` 객체를 `score` 기준 내림차순 정렬한 뒤 상위 `max_objects`(20개)만 튜플로 반환합니다.

## 5. 그래픽 유틸리티 함수 상세 (`OpenCV` 커스텀 드로잉)

### 5.1. `draw_dashed_line(img, pt1, pt2, color=(30, 30, 30), thickness=2, dash_len=8, gap_len=6)`
1. 거리 및 단위 벡터 계산: 두 점 `pt1`, `pt2` 사이의 유클리드 거리 `dist`를 `math.hypot()`으로 구하고, 방향 단위 벡터 `dx`, `dy`를 계산합니다.
2. 구간 반복 렌더링: `curr = 0`부터 `dist`보다 작을 때까지 `dash_len(8px) + gap_len(6px) = 14px` 주기로 선분을 그립니다. 배경에 밝은 회색(`(220, 220, 220)`)으로 두께 `thickness + 2`짜리 외곽선을 먼저 그린 뒤, 그 위에 어두운 회색(`(30, 30, 30)`) 본선을 겹쳐 그려 시인성을 높입니다.

### 5.2. `put_readable_text(img, text, pos, font_scale=0.5, text_color=(20, 20, 20), outline_color=(245, 245, 245), thickness=1)`
카메라 영상 배경에 글자가 묻히는 현상을 방지하기 위해, 동일한 좌표 `pos`에 `outline_color`로 두께 `thickness + 2`의 외곽선 글자를 먼저 출력한 후, 그 위에 `text_color`로 본래 두께 `thickness`의 글자를 덮어씁니다.

## 6. `main()` 초기화 및 비동기 큐 연동

### 6.1. 주요 설정 파라미터 (`config` & `audio_config`)
- 비전 설정: 해상도 `1280x720`, `15 FPS`, 객체 탐지 임계값 `0.3`, 손 추적 임계값 `0.5`, 양손 허용(`"hand": "Any"`).
- 오디오 설정: `whisper-cli` 및 `ggml-tiny.bin` 모델 사용, `espeak-ng` 및 `aplay` 연동, 출력 장치 `plughw:3,0`, 입력 장치 인덱스 `1`.

### 6.2. 비동기 음성 명령 큐(`command_queue`) 연동 메커니즘
1. `AudioService`는 백그라운드 스레드에서 에너지 기반 VAD(`UtteranceDetector`)로 발화를 감지하고 `whisper-cli`로 텍스트를 추출합니다.
2. 변환 완료 시 콜백 함수 `command_queue.put_nowait(text)`를 호출해 메인 스레드의 큐에 문자열을 넣습니다.
3. 메인 비전 루프는 블로킹 없이 매 프레임 `command_queue.get_nowait()`로 음성 명령을 꺼내어 처리하므로, STT 추론 중에도 카메라 프레임과 손 추적은 15 FPS로 끊김 없이 유지됩니다.

## 7. 핵심 상태 머신 (Finite State Machine) 및 알고리즘 분석

메인 루프(`while True:`)는 `state` 변수를 통해 3가지 상태를 순환하며 동작합니다.

### 7.1. 상태 1: `WAIT_WAKE` (시동어 대기 상태)
- 동작: 주변 소음이나 일상 대화에 시스템이 오작동하지 않도록 `check_wake_word()`를 통해 시동어를 대기합니다.
- 전이 조건: 시동어 감지 시 상태를 `"WAIT_TARGET"`으로 변경하고 `"찾을 물건을 말해주세요."` 음성 안내를 출력합니다.

### 7.2. 상태 2: `WAIT_TARGET` (목표 물체 음성 지정 상태)
- 동작: `speech.parse_input(command_text, TARGET_MAPPING, state="scanning")`을 호출하여 사용자의 발화 의도(`intent.kind`)를 분석합니다.
- 타겟 락온(Lock-on) 및 매칭:
  - `intent.kind == "target"`이고 매칭된 물체가 현재 화면의 감지된 라벨 집합(`current_detected_labels`)에 존재할 경우, 타겟을 설정하고 `"SEARCHING"` 상태로 진입합니다.
  - 화면에 없을 경우 해당 사실을 음성으로 안내합니다.
- 제어 명령 처리 (`intent.kind == "control"`):
  - `"list"`: 현재 주변에 감지된 물체 목록을 음성으로 안내합니다.
  - `"stop"`: 대기 상태(`"WAIT_WAKE"`)로 복귀합니다.
- 예외 처리: 파싱 결과에 따른 거절 사유가 있을 경우 `speech.refusal_speech(intent)`를 통해 피드백 음성을 출력합니다.

### 7.3. 상태 3: `SEARCHING` (실시간 추적, 가림 보정 및 획득 판정)

1. 실시간 음성 제어 및 상태 유지:
   - 안내 중 들어오는 음성 명령 역시 `speech.parse_input(..., state="guiding")`을 통해 실시간 처리합니다 (`"stop"` 시 안내 중지 및 초기화, `"list"` 시 목록 안내, `"repeat"` 시 현재 탐색 중인 물체 재안내).

2. 타겟 재탐색 및 위치 기억 (Target Locking & Memory):
   - 매 프레임 타겟 라벨과 일치하는 객체(`found_target`)를 찾습니다.
   - 탐지 성공 시: `locked_target_box`와 `locked_center`를 최신 좌표로 갱신하고 `missing_frame_count = 0`으로 리셋합니다.
   - 탐지 실패 시 (`found_target is None`): 손이 물체를 가렸거나 일시적 추론 누락이 발생한 상황이므로 마지막 위치를 유지하고 `missing_frame_count`를 1 증가시킵니다.

3. 다섯 손가락 끝(Fingertips) 근접 판정 (`hand_near_target`):
   - MediaPipe 손 랜드마크 중 5개 손가락 끝(`4, 8, 12, 16, 20`)과 고정된 타겟 중심점(`locked_center`) 간 거리가 `50.0 픽셀` 미만인지 검사합니다.

4. 케이스 A - 장시간 실종으로 인한 탐색 취소 (Timeout Reset):
   - 조건: `found_target is None and not hand_near_target and missing_frame_count > 45`
   - 판단: 연속 45프레임(약 3초) 이상 물체가 보이지 않으면 물건이 치워진 것으로 간주합니다.
   - 처리: `"물건을 찾을 수 없습니다. 다시 말씀해 주세요."` 안내 후 `"WAIT_TARGET"` 상태로 복귀합니다.

5. 케이스 B - 물체 획득 성공 판정 (Occlusion-based Grasp Detection):
   - 조건: `found_target is None and hand_near_target`
   - 판단: 타겟이 사라짐과 동시에 손가락 끝이 타겟 중심 50px 이내에 도달했다면 사용자가 물건을 집어 든 것으로 판정합니다.
   - 처리: `"{타겟}을(를) 찾았습니다."` 음성 안내 후 초기 상태(`"WAIT_WAKE"`)로 복귀합니다.

6. 실시간 손가락별 거리 계산 및 반투명 오버레이 시각화:
   - 탐색 중일 때는 5개 손가락 끝과 타겟 중심점 사이의 거리를 계산하여 점선(`draw_dashed_line`)으로 연결하고, 선 중앙에 거리(`px`) 텍스트를 반투명 오버레이(`cv2.addWeighted`, 투명도 75%)로 합성합니다.

## 8. OpenCV GUI 렌더링 레이어 구조 (Visual HUD)

화면 출력 창(`Capstone Vision Controller`)에는 매 프레임 다음 요소들이 렌더링됩니다:
1. 탐색 보조선 오버레이 (`SEARCHING` 상태): 다섯 손가락 끝과 타겟 중심점 간 점선 및 거리(`px`) 표시.
2. 실시간 탐지 객체 바운딩 박스: 현재 타겟은 노란색(`(0, 255, 255)`), 일반 객체는 초록색(`(0, 255, 0)`) 박스 및 빨간색 중심점 표시. 좌측 하단에는 모든 탐지 객체의 중심 픽셀 좌표 `(cx, cy)` 리스트 나열.
3. 가림 상태(`[LOCKED]`) 타겟 복원 박스: 손에 가려져 실시간 탐지는 안 되지만 `locked_target_box`가 유지 중일 때 주황색(`(0, 165, 255)`) 박스와 `[LOCKED] {라벨}` 텍스트 표시.
4. 손 랜드마크 및 스켈레톤 (`draw_hand`): 손 관절 뼈대, 손바닥 삼각형, 손가락 끝 명칭, 손등/손바닥 여부 시각화.
5. 최상단 상태 표시줄: 좌측 상단 `(10, 30)`에 현재 상태(`State`) 및 감지된 물체 리스트 표시.

## 9. 리소스 관리 및 안전 종료 메커니즘 (Lifecycle & Cleanup)
- `with CameraSource(config) as cam, HailoDetector(config) as detector, HandTracker(config) as tracker:` 컨텍스트 매니저를 통해 루프 종료 시 카메라 및 NPU, MediaPipe 리소스를 안전하게 해제합니다.
- OpenCV 창에서 `q` 키를 누르거나 `Ctrl + C`(`KeyboardInterrupt`) 발생 시 루프를 종료하고, `finally:` 블록에서 `audio_service.close()`와 `cv2.destroyAllWindows()`를 호출하여 백그라운드 오디오 스레드와 하위 프로세스까지 깔끔하게 정리합니다.

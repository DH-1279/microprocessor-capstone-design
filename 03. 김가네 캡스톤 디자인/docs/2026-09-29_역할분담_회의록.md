# 역할 분담 회의록

- 회의일: 2026-09-29
- 상태: 세부 역할 분담 확정
- 작성 근거: 회의 논의 내용과 사전 공유된 파트 구분안

## 1. 파트 구분

사전에 공유된 파트는 다음 네 가지다.

| 번호 | 파트 | 내용 |
|---|---|---|
| 1 | 핸드 인식 | MediaPipe 기반 손 인식 |
| 2 | 물체 인식 | YOLO + COCO 데이터셋 기반 인식. Kaggle·HuggingFace 등에서 데이터셋 추가 조사. 라즈베리파이에서 구동 가능한 경량 모델 선정 |
| 3 | 회로 | PCB 및 ESP32 메모리 최적화 |
| 4 | 프론트 | 라즈베리파이의 현재 손 인식 상태와 인식 중인 물체 표시, TTS·STT 구현 |

## 2. 역할 분담 결과

| 담당 | 파트 |
|---|---|
| 김민주 | 1. 핸드 인식 + 4. 프론트·TTS·STT |
| 김해수 | 2. 물체 인식 |
| 김동환 | 3. 회로 PCB + ESP32 메모리 최적화 |

## 3. 논의 내용

### 1번과 4번을 하나로 묶기로 결정

프론트 파트의 규모가 크지 않을 것으로 보여, 핸드 인식과 함께 한 명이 담당하는 방향을 논의했다. 두 작업 모두 손 인식 결과를 다루는 만큼 묶어서 진행하는 편이 낫다고 판단해 하나로 묶기로 결정했다.

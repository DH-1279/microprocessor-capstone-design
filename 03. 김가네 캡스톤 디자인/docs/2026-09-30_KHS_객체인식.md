객체 인식

## 1. MVP
실시간 객체 인식 : 책상위의 객체를 카메라로 영상을 입력받아 실시간으로 탐지한다.

좌표 추출 : 탐지된 객체의 바운딩 박스 중심 좌표와 이름 데이터를 도출한다.

## 2. 사용할 모델과 기술
사용 AI 모델 : YOLOv8n

데이터셋(추가조사) : MS COCO 데이터셋, Kaggle, Roboflow Universe

기술 스택(추가조사) : Python, OpenCV

## 3. 선택 근거
YOLOv8n : 엣지 디바이스 환경에서 연산량 대비 정확도 우수

## 4. 구현 구조
영상 캡처 : 라즈베리 파이 카메라 모듈에서 실시간 프레임 캡처

전처리(OpenCV) : 불필요한 배경을 제거하는 관심 영역 설정 및 해상도 리사이징

NPU 추론 : YOLOv8n 모델을 통한 객체 식별 및 바운딩 박스 좌표 도출

좌표 연산 : 도출된 바운딩 박스의 좌상단/우하단 좌표를 활용해 물체의 중심점 계산

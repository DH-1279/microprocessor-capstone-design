### 부품표 확인 이후 수정 사항 (최우선)

- 카메라는 **1대 사용 방향**으로 수정한다. 엑셀에 적힌 와이드·스탠다드 두 종류 중 사용할 모델은 미정이며, 아래 표는 원본 부품표 기록이다.

## 3. 착수 전에 정리할 설계 사항

1. **연산 장치:** 본문은 PC이고 예산은 Raspberry Pi용 장비를 포함한다. PC를 개발·시험용으로 쓰고 Raspberry Pi를 최종 장치로 쓸지, 최종 구성도 PC인지 확정한다. 모델 실행 가능 여부와 성능은 장치 선정 과정에서 확인한다.
2. **카메라 1대 구성:** 와이드·스탠다드 중 사용할 모델, 설치 높이와 촬영 범위를 정한다.
3. **탐색 대상과 도달 기준:** 초기 대상, 손 위치의 기준점, 허용 오차를 정한다. 영상에서 손과 물체가 겹치는 것과 실제로 집을 수 있는 위치에 도달한 것을 평가에서 구분한다.
4. **글러브 구조:** 손가락별 모터 5개의 구체적인 부착 위치, 회전·뒤집힘에 따른 방향 대응 규칙과 MPU-6050 활용 방식을 시험으로 정한다.
5. **통신과 추적 실패 처리:** BLE/Wi-Fi를 선정하고, 추적이 끊기거나 명령이 오래 갱신되지 않을 때 진동을 중단하는 조건을 정의한다.
6. **진행 관리:** 팀원별 담당, 보유 장비, 실제 구매 가능 예산, 기업 자문 일정을 확인한다.

## 4. 첫 개발 단계 제안

아래 순서와 완료 조건은 착수 제안이며 팀이 확정한 일정이나 성능 수치가 아니다.

**첫 시연 목표:** 제한된 책상 환경에서 목표 물체 하나를 선택하면 손과 물체의 상대 위치를 계산하고, 글러브 진동으로 손의 이동 방향을 알려주는 과정을 연결한다.

| 순서 | 작업 | 완료 시 확인할 결과 |
|---|---|---|
| 1 | 연산 장치·카메라 구성과 초기 대상 확정 | 시스템 구성도, 보유품 목록, 조정된 부품 예산 |
| 2 | 카메라 영상에서 목표 물체와 손 추적 | 위치를 표시한 시험 영상, 장갑 착용·회전·뒤집힘 시 인식 결과 |
| 3 | ESP32에서 손가락별 모터 5개 개별 구동 | 각 모터의 독립 제어와 착용 상태의 진동 구분 결과 |

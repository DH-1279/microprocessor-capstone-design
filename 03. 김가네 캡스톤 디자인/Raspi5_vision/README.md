# Raspberry Pi 5 영상 처리

카메라 입력, 목표 물체·손 인식, 상대 위치 계산 및 장갑 디바이스와의 통신 코드를 이 폴더에서 관리합니다.

카메라는 1대 사용 방향이며 와이드·스탠다드 중 사용할 모델과 영상 처리 실행 환경은 추후 확정합니다.

첫 무선 통신 시험은 `ble_led_control/led_control.py`로 Raspberry Pi에서 ESP32-C3 내장 LED를 제어합니다. 설치와 실행 방법은 [BLE LED 시험 안내](../docs/2026-09-17_BLE_LED_무선_통신_시험.md)에 정리했습니다.

카메라·한국어 음성·손 추적·햅틱 안내를 연결할 다음 구현 방향은 [Raspberry Pi 온디바이스 MVP 설계](../docs/2026-09-18_Raspberry_Pi_온디바이스_MVP_설계.md)에 정리했습니다. AI HAT+ 2를 사용할 예정이며, 해당 문서는 구현 전 설계안입니다.

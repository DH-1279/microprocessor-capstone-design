# 비전 기반 햅틱 글러브

> 책상 위 필요한 물건까지, 손끝의 진동으로 안내합니다.

시각장애인 및 저시력자가 실내에서 필요한 물건을 찾을 수 있도록 돕는 **카메라 기반 촉각 안내 시스템**을 개발합니다. 2026학년도 2학기 마이크로프로세서 캡스톤디자인의 김가네 팀 프로젝트입니다.

## 프로젝트가 해결하려는 문제

물건이 어디에 있는지 파악하고 그 위치까지 손을 움직이는 과정은 시각 정보를 이용하기 어려운 사용자에게 부담이 될 수 있습니다. 목표 물체와 손 사이의 위치 관계를 진동으로 전달해 사용자가 물건을 스스로 찾아 집는 과정을 돕고자 합니다.

## 핵심 구성과 기능

- **고정형 카메라 1대:** 책상 위 목표 물체와 사용자의 손을 함께 관찰합니다.
- **손가락별 진동 모터 5개:** 손을 움직일 방향과 목표 물체에 가까워지는 정도를 전달하는 패턴을 구현합니다.
- **손 자세 반영:** 손의 회전과 뒤집힘을 고려해 안내 방향을 조정하는 방식을 개발합니다.
- **장갑 전용 PCB:** ESP32, 자세 센서 및 모터 구동·전원 회로를 통합합니다.

## 사용 흐름과 목표

장갑 착용 → 목표 물체 선택 → 손·물체 추적 → 진동 안내에 따라 손 이동 → 물건 직접 확인 및 집기의 흐름을 목표로 합니다.

초기 시제품은 제한된 책상 위에서 기본 탐색 과정을 연결하는 데 집중합니다. 이후 음성 요청과 음성 안내로 기능을 확장할 계획입니다. 물체 탐색 성공률, 소요 시간, 방향 안내 정확도와 착용 편의성을 통해 결과를 평가합니다.

팀원은 김동환·김해수·김민주이며, 참여기업은 태영소프트입니다.

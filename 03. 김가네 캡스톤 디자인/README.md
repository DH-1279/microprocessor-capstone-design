# Microprocessor Capstone Design

> 2026학년도 2학기 마이크로프로세서 캡스톤디자인 프로젝트를 위한 팀 협업 저장소입니다.

## 프로젝트 개요

- **저장소 이름:** `microprocessor-capstone-design`
- **과목:** 마이크로프로세서 캡스톤디자인
- **수행 기간:** 2026년 9월 ~ 2026년 12월
- **프로젝트 주제:** 시각장애인 및 저시력자의 실내 물건 탐색을 위한 비전 기반 햅틱 글러브 시스템 개발
- **팀명:** 김가네
- **과제유형 / 참여기업:** 기업연계형 / 태영소프트
- **참여 인원:** 3명

고정형 탑뷰 카메라로 책상 위 목표 물체와 사용자의 손을 추적하고, ESP32와 손가락별 진동 모터 5개를 장착한 글러브로 이동 방향과 근접도를 안내합니다. 손의 회전·뒤집힘을 반영한 진동 안내와 필요한 음성 안내를 구현합니다. 카메라는 1대 사용 방향이며 와이드·스탠다드 중 모델은 아직 정하지 않았습니다.

2026년 9월 14일 사용자가 확정 내용을 공유한 신청서를 개발 기준으로 삼습니다. 구현 범위, 첫 작업 및 확인 사항은 [프로젝트 착수 기준](docs/2026-09-14_프로젝트_착수_기준.md)에 정리했습니다. 이 저장소는 기획, 설계, 개발, 실험 결과와 발표 자료를 팀원들이 함께 관리하기 위해 사용합니다.

선정 부품은 `김가네 부품 정리.xlsx`를 참고하되 후속 사용자 결정을 우선합니다. 파란색은 메인 카메라 쪽(AI HAT+ 2, Camera Module 3), 초록색은 장갑 디바이스 쪽(ESP32-C3 SuperMini, PN-VM102, AO3400A, MPU-6050, 배터리) 구분입니다. 엑셀에 카메라 두 종류가 기재되어 있지만 실제 구성은 1대 사용 방향으로 수정했습니다. 장갑 PCB는 사용자가 설계하며, 모터는 장갑당 5개입니다.

## 전체 목표

1. 마이크로프로세서를 활용해 실제 문제를 해결할 수 있는 프로젝트를 기획합니다.
2. 하드웨어와 소프트웨어를 연동한 시제품을 설계하고 구현합니다.
3. 역할 분담과 GitHub 협업을 통해 프로젝트를 체계적으로 관리합니다.
4. 반복적인 실험과 검증을 통해 결과물의 완성도를 높입니다.
5. 최종 시연, 발표 자료와 결과보고서를 완성합니다.

## 개발 폴더와 실행 방법

| 경로 | 용도 |
|---|---|
| `esp32_device/firmware/` | 장갑 펌웨어 및 보드·센서·모터 시험 코드 |
| `esp32_device/` | ESP32 핀맵과 장갑 디바이스 관련 자료 |
| `Raspi5_vision/` | 라즈베리파이 영상 처리와 장갑 통신 코드 |
| `docs/` | 회의, 설계, 개발 및 실험 기록 |

첫 시험은 [board_bringup.ino](esp32_device/firmware/board_bringup/board_bringup.ino)를 Arduino IDE에서 열어 진행합니다. `esp32 by Espressif Systems`를 설치하고 `ESP32C3 Dev Module`, `USB CDC On Boot: Enabled`, 연결된 COM 포트를 선택해 업로드합니다. 시리얼 모니터는 115200 baud로 설정합니다.

2026-09-15 사용자 제공 로그에서 ESP32-C3 업로드 및 해시 검증 성공, 500ms 간격 시리얼 출력이 확인되었습니다. MPU-6050, 모터 및 무선 통신 시험은 아직 진행하지 않았습니다. 자세한 설정과 문제 해결 과정은 위 초기 구동 기록을 참고합니다.
